# pxsig

Visual regression for Storybook: compact pixel signatures with their baseline images, a Rust
engine, a dashboard, a Storybook addon and an MCP server.

The published package's README is the repository's [README.md](../../README.md): the release
writes it into the tarball in place of this file (`README_SOURCE` in
[scripts/pack-manifest.mjs](../../scripts/pack-manifest.mjs)), so npm and GitHub show the same
introduction. What the package holds and exports, its peer dependencies and the network it uses
are in [docs/package.md](../../docs/package.md).
